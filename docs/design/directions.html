동물쇼기, 세 가지 얼굴

3열 4행 보드 하나에 기물은 다섯 종류뿐입니다. 규칙이 이미 최소한이라, 이 게임의 인상은 전적으로 판과 기물의 재질감에서 결정됩니다. 같은 국면을 세 가지 재질로 그렸습니다 — 나무와 먹, 색면과 블록, 선과 빛.

A

나무와 먹

桐と墨

실제 쇼기판의 재료를 그대로 가져옵니다. 오동나무 판, 옻으로 그은 선, 오각형 코마. 기물 색은 양쪽이 같고 방향만으로 편을 구분하는 원작 규칙을 지킵니다 — 판을 돌려 앉는 감각이 화면에 남습니다.

Notes

  • 코마 실루엣 오각형 clip-path. 앞쪽이 뾰족해 방향이 형태로 읽힙니다.
  • 이동 표시 붉은 점을 코마 테두리에 인쇄 — 원작의 핵심 학습 장치를 그대로.
  • 애니메이션 나무 끼리 부딪는 짧은 튕김(120ms). 잡을 때 코마가 180° 뒤집히며 손패로 날아갑니다.
  • 리스크 양쪽 색이 같아 초보자가 헷갈릴 수 있음 — 판 가장자리 색 띠로 보완 필요.

B

원과 적목

円と積み木

동물을 삼각형·사각형·원으로만 조립합니다. 기물은 진영색 원반이라 파랑이 나, 주황이 상대 — 한눈에 갈립니다. 판은 거의 흰 종이이고 색은 기물에만 있습니다. 나무 교구 상자를 태블릿에 올려놓은 쪽입니다.

C

밤과 빛

夜と光

채움을 전부 걷어내고 선만 남깁니다. 어두운 판 위에서 민트는 나, 산호색은 상대. 기물이 발광체이므로 이동 가능 칸·장군·마지막 수가 전부 빛의 세기로 표현됩니다 — 색을 더 쓰지 않고 상태를 말할 수 있습니다.

다음에 정할 것

  • 방향A·B·C 중 하나, 또는 섞기. "A의 판 + B의 기물" 같은 조합도 가능합니다.
  • 진영 구분방향만으로 구분(A) vs 색으로 구분(B·C). 규칙 충실도와 가독성의 교환입니다.
  • 이동 점 표시항상 표시 / 선택했을 때만 / 설정으로 끄기 — 초보자용 장치를 계속 켜둘지.
  • 기물 이름화면에 한글 이름을 같이 넣을지, 그림만 둘지.
